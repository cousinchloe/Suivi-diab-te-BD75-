1. Sur github.com : New repository → nom « Suivi-diab-te-BD75- », Public, rien d'autre.
2. « Upload files » : glisser les 7 fichiers (index.html, manifest.webmanifest, sw.js,
   icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png) → Commit changes.
3. Settings → Pages → Branch : main, / (root) → Save.

Adresse : https://cousinchloe.github.io/Suivi-diab-te-BD75-/

Installer : ouvrir l'adresse dans Safari → Partager → « Sur l'écran d'accueil »
(Android : Chrome → ⋮ → « Installer l'application »).
